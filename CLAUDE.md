# Rules for this repository

**Every release has a changelog.** Before tagging, add a section for the version to `CHANGELOG.md`, headed `## <version>`. Each change is one list item, starting `- New:`, `- Changed:`, `- Fixed:` or `- Removed:`, and describes the change briefly and directly. The shared Release workflow publishes that section as the release notes on GitHub, and stops if the section is missing or breaks the rules for public text. The Nexus upload then adds each line of the section to the Nexus changelog as a separate entry (`python tools/nexus_release.py lines <version>` shows them).

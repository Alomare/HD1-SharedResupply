# Shared Resupply

Brings the squad resupply from HELLDIVERS 2 to HELLDIVERS (2015), for the [Obsidian](https://github.com/Alomare/ObsidianLauncher) mod manager.

## What it does

Every player carries a yellow Resupply stratagem in every mission. It sits with the mission stratagems (Reinforce, SOS Beacon, Hellbomb), on top of the 4 picks.

- Code: ↓ ↓ ↑ →.
- Drops 1 crate with 4 ammo boxes (2 to 4 with the Ammo box count option).
- 10 second call-in. No upgrades.
- 180 second cooldown, shared by the whole squad: when anyone calls it, everyone waits. Players who join mid-mission get the current squad cooldown.

The standard (blue) Resupply is removed from the Arsenal, the Loadout screen and loadouts.

## Options

- **Preserve vanilla Resupply** (off by default): keeps the standard Resupply in the Arsenal, the Loadout screen and loadouts, with the code ↓ ↓ ↑ ↑.
- **Ammo box count** (4 by default): ammo boxes per crate, from 2 to 4. The setting of whoever calls the Resupply applies.

## Playing with others

Every player in the lobby needs Shared Resupply, at the same version and with the same Preserve vanilla Resupply setting. Saved loadouts with the standard Resupply get another stratagem instead, or keep it in the slot when no other stratagem fits. Missions leave it out either way.

Needs Obsidian API 1.40.0 or later.

# Shared Resupply

A mod for HELLDIVERS (2015) that brings the squad resupply from HELLDIVERS 2, for [Obsidian Mod Manager](https://github.com/Alomare/ObsidianModManager).

- A mission stratagem every player carries.
- Drops 4 ammo boxes.
- The cooldown is 180 seconds and is shared by the whole squad: when one player calls it in, every player waits.
- Removes the standard Resupply from the Arsenal and the Loadout.

## Option

- **Preserve vanilla Resupply** (off by default): keeps the standard Resupply in the Arsenal and the Loadout, next to the shared one. Every player in the squad needs the same setting.

Needs Obsidian API 1.40.0 or later.

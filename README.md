# Shared Resupply

A mod for HELLDIVERS (2015) that brings the squad resupply from HELLDIVERS 2, for [Obsidian Mod Manager](https://github.com/Alomare/ObsidianModManager).

## What it does

Every player carries a yellow Resupply stratagem in every mission. It is listed with the mission stratagems (Reinforce, SOS Beacon, Hellbomb), on top of the four picks.

- Code: ↓ ↓ ↑ →.
- Drops one crate with four ammunition boxes.
- Call-in time is 10 seconds. No upgrades.
- Cooldown is 180 seconds and is shared by the whole squad: when anyone calls it, everyone waits. Players who join mid-mission take the squad's current cooldown.

The standard (blue) Resupply is removed from the Arsenal, the Loadout screen and loadouts.

## Option

- **Preserve vanilla Resupply** (off by default): keeps the standard Resupply in the Arsenal, the Loadout screen and loadouts. It then uses the code ↓ ↓ ↑ ↑.

## Playing with others

Every player in the lobby needs Shared Resupply, at the same version and with the same option. Saved loadouts that held the standard Resupply get another stratagem in place of it.

Needs Obsidian API 1.40.0 or later.
